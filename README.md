# Escáner Local

Escáner de documentos sin anuncios y sin nube: todo se guarda en el dispositivo.

- Android: el instalable está en `build/app/outputs/flutter-apk/app-release.apk`
  (se vuelve a crear con `flutter build apk --release`).
- iPhone: el código está listo, pero hay que compilarlo en un Mac con Xcode
  (`flutter build ios`).
- PC (vista previa): `python main.py`.

Valores del escáner sacados de la app original: ver `MECHANICS.md`.
